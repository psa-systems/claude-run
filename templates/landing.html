Self-hosted runner

Your queue, worked by Claude Code.

claude-run is a YAML-driven runner that feeds jobs from issue trackers, forges and other sources to Claude Code, on a schedule or a webhook, and acts on the result. A web UI shows every run as it happens.

"Queue it up. I'll take it from here."

What's inside

Everything a run needs, in one binary.

Actions in YAML

Each action is one file: where its jobs come from, the prompt, and what happens with the result.

Schedules and webhooks

Poll on an interval or cron, or start the moment a forge or CI system calls in.

Budgets and limits

Spend ceilings per run and per day, attempt caps, and one pause switch honored everywhere.

Web UI with live logs

Watch each job's stream as it runs, then search past runs, reports and logs.

Secrets kept encrypted

Tokens are stored encrypted at rest and handed to a job only for the run that needs them.
