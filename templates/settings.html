YouTrack {% if let Some(url) = auth.youtrack_base_url %}{{ url }} {% else %}not set{% endif %}

Base URL and a permanent token. Equivalent to yt auth login --base-url <url>.

Forgejo {% if let Some(host) = auth.forgejo_host %}{{ host }} {% else %}not set{% endif %}

Host and an application token with write:repository and write:issue. Equivalent to fj auth add-key.

GitHub {% if let Some(host) = auth.github_host %}{{ host }} {% else %}not set{% endif %}

Host (default github.com) and a personal access token. Equivalent to gh auth login --with-token. A classic token needs repo, read:org and gist (gh's own minimum at login); a fine-grained token needs Contents and Pull requests read and write on the target repositories.

Git commit identity {{ auth.git_author_name }} <{{ auth.git_author_email }}>

Author name and email for the commits the agent makes inside a job's clone. Not a credential, so it is stored in the open. Defaults to claude-run <claude-run@a8n.run> when unset, so a fresh deployment commits successfully with no docker compose exec step. Leave a field blank to clear it back to that default.
